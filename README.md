# Nikita Khilko portfolio

This repository hosts [the portfolio](https://nkhilko.github.io/) on GitHub Pages. The current Pages source is the root of `main`. The `docs/` directory is prepared as an output-only publishing source. The site is static and uses Node.js to generate HTML and copy assets.

## Build and preview

The build is dependency-free and tested with Node.js 24.22.1. From the repository root, run:

```sh
PORTFOLIO_BASE_URL=https://nkhilko.github.io/ node build.mjs
node verify-build.mjs
python3 -m http.server 8080 --bind 127.0.0.1 --directory dist
```

Open http://127.0.0.1:8080/. The base URL supplies the canonical URL and the absolute social preview image URL. The build needs no package installation. Pass `--preview` for a self-contained page at `preview/index.html`, outside the deployment output.

## Source and publishing

| Path | Purpose |
| --- | --- |
| `src/content.mjs` | Case studies, metrics, contact links, and page copy |
| `src/diagrams.mjs` | Diagram nodes, connections, scope, and text walkthroughs |
| `src/svg.mjs` | Responsive SVG layouts and notation |
| `src/template.mjs` | Page and case study templates |
| `src/styles.css`, `src/tokens.css` | Site styling and visual tokens |
| `src/interactions.js` | Case anchors, focus, navigation, and motion |
| `src/social.png` | Social sharing image |

Edit the source, rebuild, and review the six files in `dist/`. Update the corresponding files in `docs/` in the same pull request. Run `node verify-build.mjs` to confirm the publish directory contains exactly the expected files with freshly generated bytes.

The root website files are retained during the transition. The repository owner can select **Deploy from a branch → main → /docs** in GitHub Pages settings once the output directory is on the default branch. Verify the deployment artifact and site paths after switching. GitHub's managed Pages workflow still runs third-party action code as part of publishing. Review its resolved action revisions, warnings and permissions in Actions logs after any setting change. Keep private records outside this repository.
